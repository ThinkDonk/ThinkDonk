## About

I build tools that run on infrastructure you control: self-hosted, auditable, and light on dependencies.

Public projects sit on two tracks:

- **AI coding toolchains** — OpenCode plugins, MCP servers, and developer skills shared across Claude Code, Codex, and OpenCode.
- **Video surveillance** — a GB28181 portal with per-channel authorization, signed playback URLs, full audit trails, and async recording download. FastAPI + Vue 3, one-command Docker Compose deploy.

Everything ships with Docker Compose or zero-build static files, and runs without external services.
